# GeekNosy operating workspace

Scope: responsive web application shell and the scan creation/history surface. Visitor mode: Operate. The audience is a security practitioner conducting authorized rapid audits, bug-bounty reconnaissance or repeatable posture checks. The primary task is to define an in-scope target, understand the request budget and launch the correct passive or authorized workflow. Proof comes from live service health, explicit safeguards, prior scan results and evidence-backed findings. Constraints: Spanish-first copy, keyboard access, 390–1600 px responsiveness, no secrets in browser storage beyond the existing session API key, and no active action available from the default Docker stack.
